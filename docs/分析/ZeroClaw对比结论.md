# ZeroClaw vs Poco 对比结论

> 2026-08-08

---

## 一句话总结

**ZeroClaw 赢在工程底子，输在体验和协作。**

---

## 各自最强点

| | ZeroClaw | Poco |
|--|----------|------|
| 最强 | 性能 & 安全 | UI 体验 & 协作 |
| 代表数据 | 单二进制 12MB，空闲 4MB，启动 <10ms | shadcn/ui + Plan 模式 + 团队空间 |
| 适合 | 个人生产级 agent 运行时 | 多人协作 AI 工作台 |

## 各自最大短板

| | ZeroClaw | Poco |
|--|----------|------|
| 最弱 | 权限模式粗、无协作、UI 一般 | 实时通信落后（轮询）、性能吃资源、安全面窄 |
| 致命伤 | 有 Supervised 但无 Plan 模式 | 每 3-6 秒轮询一次，延迟感知明显 |
| 部署 | 一个文件 | Docker 全家桶 |

---

## 核心概念差异

| 概念 | ZeroClaw 含义 | Poco 含义 |
|------|--------------|-----------|
| Workspace | agent 的沙箱文件目录 | 团队协作空间 |
| Channel | 消息平台入口（Telegram 等） | 多人聊天室（人+agent 混在） |
| Session | 一个对话 | 一个对话（内含多个 Run） |
| Run | 无此概念 | Session 内一次执行快照，可回放、可分支 |
| Delta | 无此概念 | HTTP 光标分页增量拉取 |
| Plan | 无此概念 | 先出方案 → 审核 → 执行 |

---

## ZeroClaw 可吸取的改进点（按优先级）

1. **Plan 模式** — Poco 最大的功能亮点，ZeroClaw 缺失
2. **UI 升级** — shadcn/ui + Tailwind + 暗色/亮色主题 + 移动端
3. **多任务排队** — agent 忙时不拒绝，排队等待
4. **会话分享** — 分享链接
5. **富内容渲染** — Mermaid/KaTeX/Excalidraw
6. **I18n** — 多语言
7. **协作基础** — 修复多用户隔离（已完成评估，待实现）

---

## Web UI 能否替换？

**不能直接换**。Poco 前端与 Poco 后端的 API/认证/实时协议深度耦合。但可走两条路：

- **A（少改）**：借 Poco 的 UI 组件库，保留 ZeroClaw 的 WS 数据层
- **B（重写）**：参照 Poco 的 UX 设计，用 ZeroClaw WS 协议从头做一个新前端

无论哪种，过程中都可以顺手把 Plan 模式设计出来。
