# ZeroClaw 聊天界面 UI 设计参考

> 参考项目：poco-claw (`/Users/sand/Documents/git/poco-claw`)
> 用途：新做聊天界面时的设计模式参考，不直接复用代码（协议不同）

---

## 1. 智能滚动

| 场景 | 行为 |
|------|------|
| 初次加载 | 直接滚到底（`auto`） |
| 新消息/流式输出 | 用户未上滚 → 平滑滚到底（`smooth`）；流式中 → 瞬间（`auto`），配合 `ResizeObserver` |
| 用户手动上滚 | 距底部 >100px → 停止自动滚动，显示"回到底部"按钮 |
| 回到底部按钮 | 圆形（40×40px），`bottom-6 right-6`，`z-10`，淡入+上滑动画（300ms），点击后平滑滚到底 |

---

## 2. 消息内容分组

消息内容分为两组格式渲染：

**纯文本：** `react-markdown` + GFM 表格 + 数学公式（KaTeX）+ 代码块语法高亮

**结构化块：** 按类型分组为连续块
- **文本块** → Markdown 渲染
- **工具调用链** → `ToolChain` 组件（可折叠卡片，见下）
- **思考块** → 左侧缩进（`pl-5`），11px `font-mono`，淡色，无边框无折叠。作为内部独白穿插展示

---

## 3. 工具调用卡片（ToolChain）

**整体：** 垂直卡片栈（间隔 16px），左侧缩进，桌面端最大宽度 `42rem`。

**卡片（折叠时）：**
- 圆角边框卡片，hover 背景微微变化
- 左侧 16×16 工具图标 → 桌面 hover 时图标消失、下拉箭头出现，暗示可展开
- 中间工具名称（11px，中等粗细，单行截断）
  - MCP 工具 → `MCP（服务名 / 动作）`
  - 浏览器工具 → `浏览器（navigate）+ URL`
  - 内置工具 → 本地化标签
- 右侧状态图标：运行中=旋转加载 ↻，失败=红色 ✗，完成=主题色 ✓

**卡片（展开后）：**
- 仅一个卡片可展开（点击其他自动收起）
- 展开面板含 INPUT / OUTPUT 两个区域
  - 小号大写标签（"INPUT" / "OUTPUT"）
  - `<pre>` 等宽字体（11px），JSON 美化展示
  - 错误输出：红色边框+红色背景

**工具图标映射：**
| 类型 | 图标 |
|------|------|
| MCP | server（服务器） |
| 浏览器 | globe/window（窗口） |
| 记忆 | brain（大脑） |
| Bash/脚本 | terminal（终端） |
| 文件读写 | file-text/file-edit（文件） |
| 搜索 | search（放大镜） |
| 技能 | sparkles（闪光） |

## 4. 打字指示器

不是简单 spinner，而是"动名词轮播"：

```
[像素动画图标] Computing█   ← 逐个字符出现，暂停，逐个删除，换词
```

- 单词列表："Analyzing"、"Computing"、"Processing"...约 57 个词，不连续重复
- 状态机：输入（70ms/字）→ 停留（1.4s）→ 删除（40ms/字）→ 间隔（320ms）
- 左边 3×3 像素图标（7 种变体轮换，2.2s 切一次，140ms 每帧）
- 尊重 `prefers-reduced-motion`：关闭动画，显示完整单词

## 5. Hover 显露规则

**桌面端：** 时间戳、token 用量、操作按钮默认透明（`opacity-0`），消息 hover 时出现（`group-hover:opacity-100`）

**移动端 / 触屏：** 始终显示（`opacity-100`）

效果：界面在默认状态下非常干净，需要时才显示辅助信息。

---

## 6. 消息操作

**助手消息底部操作栏（hover 出现）：**
- 复制 → 点击后图标短暂变为 ✓
- 点赞 → 填充变色
- 重新生成 → 可配置是否启用
- Token 用量 → 右侧对齐，等宽字体：`↑1,234 · ↓5,678 · ⏱12.4s`

**用户消息（右侧气泡）：**
- 灰色圆角背景，最大宽度 85%
- 超过 5 行折叠，点击展开
- 操作栏（hover 出现）：复制、编辑（切换为 textarea）

---

## 7. 输入框

**容器：** 底部固定，圆角边框，内部 `items-end`（按钮对齐输入区底部）

**输入区：**
- 单行 `textarea`，自动增高（最小 2rem，最大 10rem，超出滚动）
- Enter 发送，Shift+Enter 换行
- IME 输入法状态中 Enter 不发送

**发送按钮：**
- 32×32px 主题色圆角方形，上箭头图标
- 无内容时灰色禁用
- 可取消时变为暂停按钮

**斜杠命令菜单：**
- 行首输入 `/` → 弹出命令列表（绝对定位在输入框上方，同宽）
- 圆角边框+阴影，最大高度 256px，滚动
- ↑↓ 导航，Tab/Enter 选择，Esc 关闭
- 唯一精确匹配时不弹窗（直接发送）

**文件上传：**
- 上传按钮 + 隐藏文件输入
- 支持拖放（全屏虚线提示框）
- 支持粘贴文件
- 上传后显示附件卡片（带删除按钮）

## 整体风格总结

| 设计原则 | 实现方式 |
|----------|----------|
| 干净 | 辅助信息 hover 才显示 |
| 有反馈 | 复制=✓，点赞=变色，工具=状态图标 |
| 不打断 | 思考块淡色等宽、工具卡片折叠 |
| 灵动 | 打字动画轮播、消息淡入+侧滑 |
| 留白 | 16px 消息间距、24px 内容区 padding |
