# 呼吸道症候群监测

## When to use
用户问呼吸道传染病、流感、新冠、肺炎、ILI、SARI，或要看近期呼吸道流行强度。

## How to do it
1. 先取监测数据：法定传染病报告（流感、新冠、肺炎相关病种）以及门急诊 ILI%、SARI。缺一项就说明缺什么，不要编数字。
2. 用近 4–8 周说明趋势：上升、平台还是回落；点明优势病原或型别（以监测结果为准）。
3. 标出升幅较大或连续上升的地区，区分输入与本地、聚集与散发。
4. 结尾三句话：总体、需关注点、建议下一步查什么。
